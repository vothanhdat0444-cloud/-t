MECI PROJECT MANAGER V10.1 - KHONG CAN CAI NODE.JS

1. Giai nen file ZIP ra thu muc co dinh.
2. Bam chuot phai start-v10.bat > Run as administrator (lan dau Windows se hoi quyen).
3. Cho phep Windows Firewall neu co thong bao.
4. May tinh tu mo: http://localhost:8080
5. Tren dien thoai cung Wi-Fi, nhap dia chi mau vang hien trong cua so den, vi du:
   http://192.168.1.20:8080
